# Torsion Execution Layer

## Overview

The torsion execution layer extends the Yupana CRT architecture with periodic orbital dynamics.

Instead of treating modular states only as values, the system also interprets them as dynamical phase structures.

---

## Dynamical Basis

Given:

\[
f_k(x)=x^k \bmod n
\]

certain CRT-local components exhibit persistent periodic cycles.

These cycles define modular torsion.

---

## Local Torsion State

For a CRT component:

\[
x_i \in \mathbb{Z}_{p_i^{\alpha_i}}
\]

the local torsion is:

\[
\tau_i(x_i)
\]

representing orbital period under repeated application of:

\[
x_i \mapsto x_i^k
\]

---

## Torsion Vector

A global state contains:

\[
\vec{\tau}(x)=
(
\tau_1(x_1),
\dots,
\tau_r(x_r)
)
\]

This vector acts as an additional execution descriptor.
