# Why Yupana CRT Exists

## Motivation

Modern computation is dominated by:

- binary carry propagation
- sequential arithmetic
- floating-point linear algebra
- iterative convergence methods

Yupana CRT explores an alternative computational substrate.

---

# Central Idea

Instead of representing computation as sequential arithmetic over binary words:

\[
b_0,b_1,\dots,b_n
\]

Yupana CRT represents computation as:

\[
(x_1,x_2,\dots,x_r)
\]

over independent CRT domains.

---

# Consequences

This changes:

- arithmetic locality
- synchronization behavior
- memory structure
- dynamic evolution
- computational geometry

---

# Key Hypothesis

Certain classes of dynamical computation may become:

- spatially parallel
- algebraically classifiable
- latency bounded
- torsion-addressable

when expressed over modular dynamical substrates.

---

# Important Clarification

Yupana CRT is not claimed to replace classical computing.

It is an exploratory architecture for studying alternative computational geometries.
