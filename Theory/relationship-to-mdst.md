# Relationship to MDST

MDST defines the theoretical framework for modular dynamical systems over finite rings.

Yupana CRT is an implementation-oriented project derived from MDST concepts.

MDST focuses on:
- algebraic structure
- attractor classification
- torsion dynamics
- CRT geometry

Yupana CRT focuses on:
- execution models
- hardware realizations
- modular computation engines
- spatial architectures
- constant-time evaluation systems

The repositories are intentionally separated.

MDST acts as the theoretical foundation.
Yupana CRT acts as the computational realization layer.
