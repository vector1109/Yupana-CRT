# Functional Graph Dynamics

## Overview

This document describes functional graph dynamics inside the MDST and Yupana CRT framework.

The modular transformation:

\[
f_k(x)=x^k \bmod n
\]

induces a directed functional graph over the finite ring:

\[
\mathbb{Z}_n
\]

The resulting graph encodes the full asymptotic dynamics of the modular system.

---

# 1. Functional Graph Definition

Define the graph:

\[
\mathcal{G}_{n,k}
\]

where:

- each node corresponds to a modular state
- each directed edge corresponds to:

\[
x \to f_k(x)
\]

Because the map is deterministic, every node has exactly one outgoing edge.

---

# 2. Finite Dynamical Structure

Since:

\[
\mathbb{Z}_n

is finite, every connected component contains:

- transient trees

- asymptotic attractors

forming a complete finite dynamical decomposition.

The graph encodes dynamical motion through:

# 4. CRT Graph Factorization

Using CRT decomposition:

\[
\mathbb{Z}_n
\cong
\prod_i \mathbb{Z}_{p_i^{\alpha_i}}
\]

the global functional graph factorizes into local modular graph components.

The global structure emerges from the product of local dynamical graphs.
