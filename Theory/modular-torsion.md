# Modular Torsion

## Definition

Modular torsion is defined as the periodic orbital behavior of elements under modular dynamical iteration.

Given:

\[
f_k(x)=x^k \bmod n
\]

an element may:

- collapse to an idempotent attractor
- enter a nontrivial periodic cycle

The cycle structure defines its torsional behavior.

---

## Local Torsion

Inside a CRT component:

\[
\mathbb{Z}_{p^\alpha}
\]

the unit group evolves independently.

For a unit element:

\[
x \in U(p^\alpha)
\]

the torsion corresponds to the orbit length generated by repeated exponentiation.

---

## Torsion Vector

For a CRT decomposition:

\[
x \leftrightarrow (x_1,\dots,x_r)
\]

define:

\[
\vec{\tau}(x)=
(
\tau_1(x_1),
\dots,
\tau_r(x_r)
)
\]

where each component measures local orbital periodicity.

independent from nominal numeric value.
