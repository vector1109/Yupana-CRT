# Modular Torsion in Yupana CRT

## Concept

Modular torsion is a dynamical invariant associated with periodic orbital behavior inside CRT-local unit groups.

It represents a computational degree of freedom independent from nominal numeric value.

---

## Dynamical Context

Given:

\[
f_k(x)=x^k \bmod n
\]

and the CRT decomposition:

\[
\mathbb{Z}_n
\cong
\prod_i \mathbb{Z}_{p_i^{\alpha_i}}
\]

each component evolves independently.

Certain components collapse toward idempotents.

Others remain trapped inside periodic cycles.

These persistent cycles define torsion structure.

---

## Local Torsion

Inside a component:

\[
\mathbb{Z}_{p^\alpha}
\]

let:

\[
U(p^\alpha)
\]

be the unit group.

For:

\[
x \in U(p^\alpha)
\]

the local torsion is the orbital period:

\[
\tau_{p^\alpha}(x)
\]

under repeated application of:

\[
x \mapsto x^k
\]

---

## Interpretation

Torsion measures:

- persistent cyclic behavior
- orbital memory
- dynamical phase structure

rather than arithmetic magnitude.

---

## Torsion Vector

For a CRT state:

\[
x=(x_1,\dots,x_r)
\]

the torsion vector is:

\[
\vec{\tau}(x)=
(
\tau_1(x_1),
\dots,
\tau_r(x_r)
)
\]

This vector acts as a fine dynamical signature.

---

## Computational Meaning

Torsion introduces:

- phase-based information
- periodic state encoding
- modular oscillatory behavior
- non-boolean dynamical structure

---

## Relationship to Phi

The MDST operator:

\[
\Phi(x)
\]

identifies the attractor basin.

The torsion vector identifies:

- whether convergence occurs
- whether cyclic persistence exists
- the local orbital periods

Together they define a finer classification of modular dynamics.
