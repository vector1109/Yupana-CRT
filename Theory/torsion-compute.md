# Torsion-Oriented Computation

## Overview

In Yupana CRT, computation is not only determined by numerical state values, but also by their dynamical torsion signatures.

A system state possesses:

- nominal value
- attractor basin
- torsion class
- orbital phase

This introduces a computational degree of freedom absent from classical Boolean architectures.

---

## Torsion as Computational Structure

Under:

x -> x^k mod n

certain CRT components enter periodic cycles instead of converging directly to fixed points.

These cycles define:

- discrete oscillators
- phase-preserving memory states
- torsion-stable execution modes

---

## Computational Interpretation

A torsion cycle of length L may encode:

- phase information
- local clock states
- dynamical memory
- modular synchronization states

without requiring explicit register updates.

## Key Insight

Classical systems compute over values.

Yupana CRT computes over:

- values

- orbital geometry

simultaneously.
