# CRT Dynamical Foundations

## Overview

This document summarizes the mathematical foundations underlying the CRT-based dynamical framework used by MDST and Yupana CRT.

The central idea is that modular exponentiation over finite rings admits a fully decomposable dynamical structure through the Chinese Remainder Theorem.

---

# 1. Finite Ring Structure

Let:

\[
n=\prod_{i=1}^{r} p_i^{\alpha_i}
\]

with distinct prime factors:

\[
p_i
\]

The finite ring:

\[
\mathbb{Z}_n
\]

admits the decomposition:

\[
\mathbb{Z}_n
\cong
\prod_{i=1}^{r}\mathbb{Z}_{p_i^{\alpha_i}}
\]

through CRT isomorphism.

---

# 2. Dynamical System

Define the modular dynamical map:

\[
f_k(x)=x^k \bmod n
\]

for:

\[
k\geq1
\]

This induces a finite discrete dynamical system over:

\[
\mathbb{Z}_n
\]

---

# 3. Component-Wise Evolution

Under CRT decomposition:

\[
x
\leftrightarrow
(x_1,x_2,\dots,x_r)
\]

the dynamics factorize:

\[
f_k(x_1,\dots,x_r)
=
(x_1^k,\dots,x_r^k)
\]

Each component evolves independently.

---

# 4. Dynamical Consequences

The decomposition implies:

- local evolution
- independent modular dynamics
- separable orbital structure
- distributed attractor behavior

inside the global system.

---

# 5. Functional Graph Structure

The map:

\[
f_k
\]

defines a functional graph over:

\[
\mathbb{Z}_n
\]

whose structure contains:

- fixed points
- transient trees
- periodic cycles
- attractor basins

---

# 6. Idempotent Attractors

Idempotent elements satisfy:

\[
e^2=e
\]

Such elements act as stable dynamical attractors for large classes of states.

CRT decomposition allows direct identification of these attractors.

---

# 7. Φ Classification

The operator:

\[
\Phi(x)
\]

classifies elements according to their asymptotic basin structure.

This classification avoids explicit orbit simulation.

---

# 8. Torsional Structure

Inside unit groups:

\[
U(p^\alpha)
\]

certain elements enter periodic orbital cycles.

These cycles define modular torsion structures captured through:

\[
\vec{\tau}(x)
\]

---

The CRT decomposition induces a discrete product geometry.

The modular space may be interpreted as:

- a finite toroidal structure
- a basin-partitioned phase space
- a directed orbital geometry

generated by modular evolution.
