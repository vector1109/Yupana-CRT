# Idempotent Attractors

## Overview

This document describes the role of idempotent elements as asymptotic attractors within modular dynamical systems.

Inside the MDST and Yupana CRT framework, idempotents are interpreted as stable structural endpoints of modular evolution.

---

# 1. Idempotent Elements

An element:

\[
e \in \mathbb{Z}_n
\]

is idempotent if:

\[
e^2 \equiv e \pmod n
\]

Equivalently:

\[
e(e-1)\equiv0 \pmod n
\]

---

# 2. CRT Structure of Idempotents

Using CRT decomposition:

\[
\mathbb{Z}_n
\cong
\prod_i \mathbb{Z}_{p_i^{\alpha_i}}
\]

each local component admits two idempotent states:

\[
0
\quad\text{or}\quad
1
\]

Therefore the global idempotents correspond to binary CRT configurations.

---

# 3. Asymptotic Interpretation

Under repeated modular evolution:

\[
f_k(x)=x^k \bmod n
\]

many trajectories asymptotically organize around idempotent sectors.

The framework interprets these sectors as attractor regions.

---

# 4. Basin Association

The operator:

\[
\Phi(x)
\]

maps states into idempotent asymptotic classes.

Each idempotent therefore acts as a basin label for modular dynamical flow.

---

# 5. Dynamical Stability

Idempotents possess structural stability because:

\[
e^k \equiv e \pmod n
\]

for all:

\[
k\ge1
\]

Thus they remain invariant under modular exponentiation dynamics.

---

Inside modular phase spaces, idempotents behave as:

- asymptotic anchors
- basin centers
- orbital sinks
- structural fixed regions

within the finite geometry.

---

Because local CRT components choose between:

\[
0
\]

and:

\[
1

This creates:

- asymptotic partitions
- attractor sectors
- basin lattices
- structural decomposition

inside:

\[
\mathbb{Z}_n
\]

Together they define a layered asymptotic description.
