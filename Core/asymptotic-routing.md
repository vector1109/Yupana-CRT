# Asymptotic Routing

## Overview

This document describes asymptotic routing within the MDST and Yupana CRT framework.

The framework explores whether modular dynamical systems may support computation through structural attractor navigation rather than explicit sequential arithmetic traversal.

\[
f_k(x)=x^k \bmod n

\[
\mathbb{Z}_n
