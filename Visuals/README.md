# Visuals — Yupana CRT

## Purpose

The Visuals layer represents the geometric and dynamical structure of CRT-based modular computation.

Yupana CRT interprets computation not only as arithmetic, but as motion through structured finite spaces.

---

## Visualization Targets

The project explores visual representations of:

- CRT decompositions
- attractor basins
- functional graphs
- torsion cycles
- modular phase spaces
- discrete toroidal geometries

---

## Core Structures

### Functional Graphs

Directed graphs representing:

\[
x \to f(x)
\]

for modular dynamical systems.

These graphs contain:

- fixed points
- cycles
- transient trees
- basin structures

---

### Basin Atlases

Partition maps induced by:

\[
\Phi(x)
\]

showing asymptotic attractor regions.

---

### CRT Toroidal Geometry

CRT decomposition naturally induces spatial product geometries.

These structures may be visualized as:

- discrete tori
- layered modular manifolds
- cyclic phase lattices

---

### Torsion Maps

Visual representations of periodic orbital behavior.

These maps encode:

- cycle length
- phase structure
- orbital persistence
- dynamical memory regions
