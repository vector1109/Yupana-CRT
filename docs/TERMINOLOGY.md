# Terminology

## Overview

This document defines recurring terminology used throughout the MDST and Yupana CRT framework.

The definitions are conceptual and may evolve as the framework becomes more formalized.

---

# 1. MDST

**MDST** stands for:

\[
\text{Modular Dynamical Systems Toolkit}
\]

It refers to the theoretical framework investigating modular dynamical systems over finite rings.

---

# 2. Yupana CRT

**Yupana CRT** refers to the computational and architectural interpretation derived from MDST concepts.

The project explores CRT-local execution and modular dynamical computation.

---

# 3. CRT

**CRT** refers to the Chinese Remainder Theorem.

Within the framework it acts as:

- a decomposition mechanism
- a coordinate system
- a computational partition
- a geometric factorization

for modular systems.

---

# 4. Modular Dynamical System

A modular dynamical system is a transformation such as:

\[
f_k(x)=x^k \bmod n
\]

acting over a finite ring.

Repeated application generates finite orbital dynamics.

---

# 5. Phase Space

The finite ring:

\[
\mathbb{Z}_n
\]

is interpreted as a discrete phase space containing dynamical trajectories.

---

# 6. Functional Graph

The directed graph generated by:

\[
x \to f_k(x)
\]

is called the functional graph.

It encodes the full asymptotic dynamics of the system.

---

# 7. Basin

A basin is the set of states converging toward the same asymptotic attractor.

Basins partition the modular phase space.

---

# 8. Attractor

An attractor is a stable asymptotic structure including:

- fixed points
- periodic cycles
- recurrent orbital cores

inside the modular system.

---

# 9. Idempotent Attractor

An idempotent attractor is an idempotent element:

\[
e^2\equiv e \pmod n
\]

interpreted as an asymptotic basin anchor.

---

# 10. Φ Operator

The operator:

\[
\Phi(x)
\]

is the asymptotic basin classifier.

It maps states into attractor sectors through CRT-local classification.

---

# 11. Torsion

Torsion refers to periodic orbital structure inside modular dynamics.

It describes recurrent cyclic behavior.

---

# 12. Torsion Vector

The torsion descriptor:

\[
\vec{\tau}(x)
\]

captures local periodic structure across CRT components.

---

# 13. CRT-Local Execution

CRT-local execution refers to computation performed independently inside CRT-decomposed modular domains.

---

# 14. Orbital Structure

Orbital structure refers to the collection of:

- trajectories
- cycles
- recurrent loops
- transient pathways

inside modular phase space.

---

# 15. Basin Topology

Basin topology describes the asymptotic partitioning of modular phase space into attractor regions.

---

# 16. Phase Atlas

A phase atlas is a geometric interpretation of CRT-decomposed modular phase space as a collection of local dynamical charts.

---

# 17. Modular Routing Fabric

A modular routing fabric is a speculative hardware interpretation where computation flows through CRT-local execution regions.

---

# 18. Asymptotic Classification

Asymptotic classification refers to identifying long-term dynamical behavior structurally rather than through explicit iteration.

---

# 19. Toroidal Geometry

Toroidal geometry refers to cyclic CRT coordinate structure induced by periodic modular evolution.

---

# 20. Research Status

All terminology should currently be interpreted as exploratory conceptual language rather than finalized scientific nomenclature.
