# Terminology

## Overview

This document defines core terminology used throughout the MDST and Yupana CRT framework.

Many terms are exploratory and should not necessarily be interpreted as formally established mathematical objects.

---

# 1. Modular Phase Space

A finite modular ring:

\[
\mathbb{Z}_n
\]

interpreted as a discrete dynamical state space supporting orbital evolution.

---

# 2. Orbital Dynamics

Repeated modular evolution generated by:

\[
f_k(x)=x^k \bmod n
\]

inside finite modular phase spaces.

---

# 3. Orbital Trajectory

A sequence:

\[
x,
f_k(x),
f_k^{(2)}(x),
\dots
\]

generated through repeated modular transformation.

---

# 4. Basin

The set of states whose trajectories converge toward the same asymptotic attractor structure.

---

# 5. Basin Topology

The global partitioning of modular phase space into asymptotic attractor regions.

---

# 6. Asymptotic Sector

A dynamical region containing states with common long-term recurrent organization.

---

# 7. Torsion Vector

The conceptual descriptor:

\[
\vec{\tau}(x)
\]

summarizing recurrent periodic structure across CRT-local modular domains.

The formal definition remains incomplete.

---

# 8. CRT Phase Atlas

The collection of CRT-local coordinate charts describing modular dynamical organization.

---

# 9. Orbital Flow Field

The directed global transition structure generated by:

\[
x \to f_k(x)
\]

across modular phase space.

---

# 10. Recurrent Orbital Geometry

The geometric organization generated by periodic modular recurrence and asymptotic orbital flow.

---

# 11. Functional Graph Manifold

The interpretation of the functional graph:

\[
\mathcal{G}_{n,k}
\]

as a discrete orbital geometric structure.

---

# 12. Modular Attractor Network

The interconnected system of recurrent attractor regions and basin relationships inside modular phase space.

---

# 13. Distributed Orbital Computation

A speculative computational paradigm based on distributed modular orbital evolution rather than centralized symbolic arithmetic alone.

---

# 14. Lookup-Driven Dynamics

Execution through bounded local transition tables:

\[
T[a]=f(a)
\]

instead of explicit arithmetic recomputation.

---

# 15. Asymptotic Routing

A speculative computational interpretation where state evolution navigates attractor-oriented asymptotic sectors.

---

# 16. Orbital Execution Fabric

A speculative distributed hardware architecture composed of CRT-local modular execution regions.

---

# 17. Torsional Synchronization

Potential recurrent phase coordination emerging from periodic orbital structure inside distributed modular systems.

---

# 18. Finite-State Orbital Processing

A computational interpretation viewing modular dynamics as finite-state orbital evolution.

---

# 19. Toroidal Phase Geometry

The interpretation of CRT-local cyclic coordinates as toroidal recurrent geometry.

---

# 20. Research Status

Most terminology in this framework remains:

- conceptual
- exploratory
- partially formalized
- experimentally unvalidated

rather than established scientific vocabulary.
