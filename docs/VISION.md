# Yupana CRT — Vision

## Purpose

Yupana CRT explores an alternative computational substrate based on modular dynamical systems and CRT decomposition.

The project investigates whether computation can be reformulated as:

- spatial modular evolution
- attractor navigation
- torsion-driven dynamics
- constant-time local inference

rather than sequential binary arithmetic.

---

## Core Idea

Traditional processors depend on:

- binary representation
- carry propagation
- sequential arithmetic pipelines

Yupana CRT replaces this with:

- CRT-local channels
- table-driven execution
- independent modular dynamics
- finite-state attractor systems

---

## Foundational Principles

### 1. Computation as Dynamics

Execution is interpreted as movement through a finite dynamical graph.

---

### 2. Spatial Decomposition

Global state is decomposed into independent CRT components.

---

### 3. Non-Iterative Classification

The MDST operator:

\[
\Phi(x)
\]

classifies asymptotic behavior without simulation.

---

### 4. Torsion as Computation

Periodic modular cycles become computational resources.
