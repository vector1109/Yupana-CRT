# Paper Directions — Yupana CRT

## Purpose

This document outlines possible academic publication directions related to the Yupana CRT framework and its relationship with MDST.

---

## Potential Publication Areas

### 1. Finite Dynamical Systems

Topics:

- modular exponent dynamics
- functional graph decomposition
- attractor basin classification
- CRT dynamical factorization

Possible venues:

- Discrete Mathematics
- Journal of Number Theory
- Advances in Applied Mathematics

---

### 2. Theoretical Computer Science

Topics:

- non-iterative attractor classification
- finite-state computational geometry
- torsion-aware computation
- modular execution semantics

Possible venues:

- Theoretical Computer Science
- Theory of Computing Systems
- Fundamenta Informaticae

---

### 3. Hardware Architecture

Topics:

- CRT-local execution fabrics
- carry-free modular architectures
- FPGA dynamical accelerators
- table-driven execution systems

Possible venues:

- IEEE FPGA
- ACM/IEEE architecture workshops
- FPL conference

---

### 4. Neural and Dynamical AI Systems

Exploratory directions:

- modular neural substrates
- torsion-based recurrent structures
- finite-state attractor learning
- discrete dynamical inference

These directions remain speculative.

---

## Immediate Requirements

Before formal publication:

- rigorous theorem proofs
- literature review
- benchmark implementation
- complexity analysis
- comparison with existing RNS systems
- comparison with functional graph literature

---

## Important Position

The project currently presents:

- exploratory theoretical structures
- architectural hypotheses
- formal dynamical observations

It does NOT yet present:

- production hardware
- validated acceleration benchmarks
- experimentally verified superiority

---

## Long-Term Objective

To determine whether modular dynamical systems can support practical computational substrates distinct from conventional binary architectures.
